# Model Versions

This study was conducted in two experimental phases.

---

# Phase 1 — Model Screening

Purpose

Initial evaluation of candidate Large Language Models using a synthetic benchmark for model selection.

Experiment

Synthetic student responses

Evaluation Period

July 2025

Models

| Model | Provider | Access Period |
|--------|----------|---------------|
| ChatGPT-4o | OpenAI | July 2025 |
| Gemini 2.0 Pro | Google | July 2025 |
| Claude 4 Sonnet | Anthropic | July 2025 |
| Grok 4 (Generalist) | xAI | July 2025 |
| Typhoon 2 Instruct (70B) | SCB 10X | July 2025 |

---

# Phase 2 — Main Adversarial Evaluation

Purpose

Evaluation using the six controlled student profiles (Students 1–6), including both baseline and adversarial conditions.

Evaluation Period

April 2026

Models

| Model | Provider | Access Period |
|--------|----------|---------------|
| Gemini 3.1 Pro | Google | April 2026 |
| Claude 4.6 Sonnet | Anthropic | April 2026 |

Notes

Phase 2 was conducted using the latest available versions of the two selected model families to assess whether improvements observed in newer releases affected the robustness conclusions reported in this study.
