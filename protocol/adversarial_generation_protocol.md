# Adversarial Response Construction Protocol

## Objective

To evaluate whether LLM-based grading relies primarily on lexical matching or semantic understanding.

---

## Student Profiles

Student 1

High-performing baseline.

Student 2

Above-average baseline.

Student 3

Average baseline.

Student 4

Low-performing baseline.

Student 5

Keyword Adversarial

Responses intentionally contain the expected rubric keywords while distorting the underlying semantic meaning or logical relationships.

Purpose

Evaluate keyword inflation.

Student 6

Semantic Adversarial

Responses remain semantically correct while deliberately avoiding the expected rubric keywords through paraphrasing or synonymous expressions.

Purpose

Evaluate semantic undervaluation.

---

## Design Principle

Each student profile answered the same set of 55 examination questions.

Only the response style varied across profiles.

This design isolates the effect of lexical manipulation while controlling for question difficulty.
