# Reason Code Annotation Protocol

## Objective

Evaluate whether AI systems assign scores for the same reasons as human teachers.

---

## Human Annotation

Teacher 1

↓

Assign score

↓

Assign reason code

---

Teacher 2

↓

Assign score

↓

Assign reason code

---

## AI Annotation

Each LLM generated

• Numerical score

• Free-text explanation

Human annotators subsequently mapped the AI explanations to the predefined reason code taxonomy.

---

## Reason Codes

R1

Missing Key Concept

R2

Incomplete Explanation

R3

Correct and Complete

R4

Irrelevant Content

R5

Misinterpretation
