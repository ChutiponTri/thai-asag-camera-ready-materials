# Supplementary Materials

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21762005.svg)](https://doi.org/10.5281/zenodo.21762005)

This repository contains the supplementary materials accompanying the paper

**"Assessing LLM Performance in Automated Short Answer Grading for Thai Written Exams: An Adversarial Evaluation"**

accepted for publication at the

**34th International Conference on Computers in Education (ICCE 2026)**

Christchurch, New Zealand

The repository provides the materials required to facilitate the reproducibility of the experiments reported in the paper, including prompt templates, model information, evaluation protocols, and illustrative examples.

## Repository Contents

- Prompt templates
- Model version identifiers
- API access dates
- Evaluation protocol
- Adversarial-response construction protocol
- Example grading cases
- Supplementary document
