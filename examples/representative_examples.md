# Representative Grading Examples

This document presents representative examples illustrating how the proposed grading framework evaluates Thai-language written responses under different cognitive levels and scoring outcomes.

Each example contains

- Examination question
- Bloom's Taxonomy level
- Rubric criteria
- Student response
- Teacher score
- Teacher explanation
- Assigned reason code

---

# Example 1 — Remembering (Full Score)

## Question

Who is the author of *Suphasit Son Ying*?

## Bloom's Taxonomy

Remembering

## Rubric

Expected concept

- Sunthorn Phu

## Student Response

"Sunthorn Phu"

## Teacher Score

3 / 3

## Teacher Explanation

The response exactly matches the expected answer.

## Reason Code

R3 — Correct and Complete

---

# Example 2 — Remembering (Partial Credit)

## Question

What is the function of an adjective?

## Bloom's Taxonomy

Remembering

## Rubric

Expected concepts

• modifies another word

• noun / verb / adjective

• provides additional detail

## Student Response

"It describes characteristics or properties to make the sentence clearer."

## Teacher Score

2 / 3

## Teacher Explanation

The response correctly explains that adjectives modify meaning and provide additional detail, but it omits the grammatical categories being modified.

## Reason Code

R1 — Missing Key Concept

# Example 3 — Analyzing

## Question

Determine the communicative purpose of the following statement.

"Ultraviolet radiation causes skin darkening."

## Bloom's Taxonomy

Analyzing

## Rubric

Expected concepts

• informative speech

• provides information

## Student Response

"The statement presents factual scientific information to improve understanding of the effects of ultraviolet radiation."

## Teacher Score

3 / 3

## Teacher Explanation

Although the student does not literally use the phrase "informative speech", the semantic meaning clearly corresponds to the intended communicative purpose.

## Reason Code

R3 — Correct and Complete
